# PROJECT VISION: "银图PMC智能分析平台"

## 1. 使命 (Mission)

构建一个智能PMC（生产计划与物料控制）分析平台，通过数据驱动的ROI分析和智能供应商选择，解决制造业缺料导致的生产停滞问题，为管理层提供快速、精准的生产排期决策支持。

## 2. 核心用户体验 (Core User Journeys)

- **"5分钟决策"**：管理层上传订单数据，5分钟内获得完整的ROI分析报告和生产优先级建议。
- **"智能排产"**：基于ROI计算自动推荐最优生产顺序，优先安排高回报率订单，最大化资金效率。
- **"精准采购"**：自动匹配最低价供应商，提供详细的欠料采购清单和投资回报分析。

## 3. 指导原则 (Guiding Principles)

- **数据准确性第一**：所有分析结果必须基于准确数据，错误的分析比没有分析更危险。
- **快速响应决策**：从数据上传到报告生成，整个流程控制在5分钟内，支持紧急生产决策。
- **ROI驱动优化**：一切功能围绕提升ROI（从2.5倍目标提升至3.0倍）和降低缺料率（目标降低40%）。

## 4. 明确边界 (What This Is NOT)

- **不是**生产执行系统（MES），不负责具体生产操作和现场管理。
- **不是**库存管理系统（WMS），不处理实时库存变动和仓库操作。
- **不是**ERP替代品，专注于PMC分析决策，不涵盖财务、人事等其他业务模块。
