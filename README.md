# 🎯 银图PMC智能分析平台

## 项目简介

银图PMC智能分析平台是专为hair dryer制造企业设计的生产计划与物料控制系统。基于560个生产订单的全面分析，为管理层提供数据驱动的决策支持。

## ✨ 核心功能

### 📊 订单分析
- **560个订单全覆盖** - 包含PSO、RSO、MSO、TSO等全类型订单
- **ROI计算** - 基于订单金额/欠料金额的投资回报率分析
- **优先级排序** - 智能生产排期建议

### 💰 财务洞察
- **总订单价值**: ¥100,909,548.93
- **总欠料金额**: ¥13,086,682.06  
- **整体ROI**: 7.71倍（优秀水平）
- **可立即生产**: 94个订单（16.8%）

### 🏭 供应商管理
- **155家供应商** - 全面的采购网络分析
- **998种物料** - 详细的采购需求清单
- **成本优化** - 最低价供应商自动选择

## 🔧 技术架构

### 数据源
- 订单数据：8月/9月国内+柬埔寨订单
- 欠料数据：实时物料短缺情况
- 库存数据：价格和可用性信息
- 供应商数据：采购价格和交期信息

### 技术栈
- **前端**: Streamlit + Plotly
- **数据处理**: Pandas + NumPy
- **部署**: Streamlit Cloud
- **文件处理**: OpenPyXL
